# 03. Scene Types

Документ описывает базовые типы игровых сцен для проекта «Осколки Реальности».

## Основной принцип

Тип сцены определяет:

- как сцена отображается;
- какой UI используется;
- какие механики доступны;
- как сцена обрабатывается движком.

Тип сцены не должен описывать сюжет.

Плохо:

```text
phone_call
sad_scene
happy_scene
```

Хорошо:

```text
dialogue
combat
travel
```

## Базовые типы

### story

Обычная сюжетная сцена.

Используется для:

- описаний;
- повествования;
- внутренних монологов;
- небольших выборов.

Примеры:

- пробуждение;
- осмотр комнаты;
- воспоминание.

### dialogue

Диалог.

Особенности:

- отображение портрета NPC;
- варианты ответа;
- изменение отношений.

Примеры:

- разговор с Монахом;
- разговор с Хранителем;
- допрос культиста.

### exploration

Исследование.

Игрок изучает место.

Примеры:

- квартира;
- база Хранителей;
- заброшенная церковь.

Внутри exploration обычно есть действия:

- осмотреть стол;
- осмотреть дверь;
- осмотреть карту.

### travel

Перемещение между локациями.

Важный тип для проекта.

Используется для:

- поездок по городу;
- перемещения между районами;
- путешествий между слоями;
- преследований;
- побегов.

Примеры:

- поездка на базу;
- поездка через город;
- переход через тоннель;
- погоня по шоссе.

Во время travel могут происходить события:

- засада;
- случайная встреча;
- звонок;
- появление противника.

### combat

Бой.

Использует отдельный UI.

Подходит для:

- людей;
- культистов;
- демонов;
- боссов.

### cutscene

Катсцена.

Игрок ничего не выбирает.

Используется для:

- воспоминаний;
- видений;
- вступления;
- финалов.

### choice

Критически важное решение.

Обычно содержит мало текста. Главное — последствия.

Примеры:

- спасти Монаха;
- спасти Печать.

### ending

Концовка.

Использует специальный экран завершения игры.

## Подтипы

### Подтипы для story

- `intro` — вступление.
- `memory` — воспоминание.
- `dream` — сон.
- `investigation` — расследование.

### Подтипы для dialogue

- `briefing` — получение задания.
- `interrogation` — допрос.
- `companion` — разговор со спутником.
- `merchant` — торговец.

### Подтипы для travel

- `city` — передвижение по городу.
- `highway` — поездка между городами.
- `pursuit` — погоня.
- `escape` — побег.
- `layer_shift` — переход между слоями реальности.
- `patrol` — патрулирование территории.

### Подтипы для combat

- `normal` — обычный бой.
- `ambush` — засада.
- `duel` — дуэль.
- `boss` — бой с боссом.
- `defense` — оборона объекта.

### Подтипы для exploration

- `room` — комната.
- `building` — здание.
- `district` — район.
- `dungeon` — подземелье.
- `base` — база.

## Теги

Теги используются для атмосферы, фильтрации и дополнительных правил отображения.

Примеры:

- `night`
- `rain`
- `fog`
- `safe_zone`
- `combat_zone`
- `hell_influence`
- `layer1`
- `layer5`
- `story_critical`
- `optional`

## Рекомендуемый набор для первой версии

В первой версии достаточно использовать основные типы:

- `story`
- `dialogue`
- `exploration`
- `travel`
- `combat`
- `cutscene`
- `choice`
- `ending`

Подтипы можно добавлять по мере роста проекта.

## Примеры

### Поездка на базу

```json
{
  "type": "travel",
  "subtype": "city"
}
```

### Засада на дороге

```json
{
  "type": "combat",
  "subtype": "ambush"
}
```

### Разговор с Монахом

```json
{
  "type": "dialogue",
  "subtype": "briefing"
}
```

### Осмотр квартиры

```json
{
  "type": "exploration",
  "subtype": "room"
}
```

### Переход во второй слой

```json
{
  "type": "travel",
  "subtype": "layer_shift"
}
```
