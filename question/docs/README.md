# Осколки Реальности — документация

Версия документации: `0.1.0`
Статус: в разработке

Документация проекта хранится в Markdown. PDF-файлы считаются исходными материалами и архивными экспортами, но рабочим источником правды должна быть папка `docs/`.

## Как устроена документация

Документация разделена на короткие независимые главы. Каждая глава отвечает за одну область проекта: философию, мир, архитектуру, сцены, правила контента или техническую спецификацию.

Такой формат удобен для трёх задач:

- быстро находить канон по игре;
- использовать документы как инструкции для AI-агентов;
- постепенно превращать правила в JSON-схемы, backend-модули и frontend-компоненты.

## Правила оформления новых глав

Каждая новая глава должна иметь:

- короткое назначение документа;
- список правил или требований;
- примеры там, где есть формат данных или игровые сущности;
- раздел `Открытые вопросы`, если решение ещё не принято;
- стабильное имя файла на английском языке.

Рекомендуемый формат имени:

```text
NN_Document_Name.md
```

Пример:

```text
07_Backend_Architecture.md
08_Frontend_Architecture.md
```
